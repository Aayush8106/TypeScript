# 🚀 My TypeScript Learning Journey

Welcome to my **TypeScript learning journey**!

I am starting my journey to learn TypeScript **from scratch**, one small step at a time.

The goal isn't to rush through TypeScript or learn everything in a single day. Instead, I want to spend a little time every day learning something new, practicing it, and documenting my progress here.

---

## 🎯 My Goal

I want to build a strong understanding of TypeScript from the fundamentals and eventually use it to build real-world web applications.

My learning path will roughly be:

    TypeScript Basics
          ↓
    TypeScript + Web
          ↓
    TypeScript Projects
          ↓
    React
          ↓
    React + TypeScript
          ↓
    Real-world Applications

---

## 📅 Daily Learning

I will be organizing my learning into separate days.

Each day will contain:

- 📚 What I learned
- 💻 Code and practice
- 🧪 Small experiments
- 🛠️ Projects I built
- 📝 Notes and important concepts

This repository will act as a record of my progress.

---

## 🌱 Learning Philosophy

I am learning this **from scratch**, so the focus is on understanding concepts rather than simply copying code.

The plan is simple:

> **Learn a little → Practice it → Build something → Document it → Repeat.**

There will definitely be mistakes, errors, bugs, and things I don't understand immediately.

That's part of the journey.

This repository is here to show the **actual progress**, not just the final result.
